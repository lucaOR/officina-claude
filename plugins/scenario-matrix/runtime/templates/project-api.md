## Project levers

This section documents the levers this project wrote itself, the ones re-exported from `project-exports.mjs`. The core and the installed adapters document theirs in the sections above.

Write one entry per lever: its signature, what it observes or does, the failure it raises (`Blocked` when the environment is at fault, `Ko` when the product is), and the matrix rows that use it. A lever that reaches a new technology also answers the five questions in its header comment: how it is stood up for real, how you know it is ready without waiting a fixed time, what deterministic marker shows it processed something, how you force it to fail and undo that, and what it does that the others do not.
